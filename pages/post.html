What is JLI?

Foundations

Introduction

The Just Learn IT project is an open-source solution for providing the best educational sources to let you learn what you desire.

This post is an introduction to getting to know how the whole project and the site work.

How does it work?

But let's start from the beginning. How do we want to provide educational materials on the site? It's simple. This site contains a course section where you can actually find all the content in the form of text posts. For now, posts are in the form of unordered lists. Every post will contain fully accessible educational materials in text format, available for free. Besides that, at the end of every post there will be more links worth checking out if you want to go much deeper into a specific topic. Posts will be written in a way that does not require checking them that much. But hey, if you want to go deeper into some topic, we will provide that solution too.

Future project development

We know that currently this site does not provide many features. We're trying to improve that and provide you with the best content we can. But it requires time. We are committed to ensuring that both the new features on the website and the content we publish are of the highest quality, which is why we will be rolling them out on an irregular basis. We have plenty of ideas, but unfortunately time is limited, and we want to do this as well as possible.

Simplicity

The site’s simplicity also stems from our approach to creating educational materials. In an age where today’s media influence our ability to focus, we opted for the simplest possible design, one that requires a certain amount of adjustment on the part of anyone who wants to learn something. You won’t find any flashy effects or dopamine-inducing elements here, unlike with short-form content.

Open source

The entire project website is open source and available on GitHub as of the time of writing this post (the link will be provided in the sources). We encourage you to contribute your own features to the site if you have the necessary expertise and your code was not generated by AI.

Summary

In summary, we want both us and our readers to give each other a chance, while understanding that some things take time to refine. We believe that anyone can learn anything, and we want to create a platform for that, but it takes time. Let’s trust each other.
